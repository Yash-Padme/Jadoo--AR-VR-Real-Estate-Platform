# 03. User Personas: Jadoo

## 1. Purpose

Define the target users for Jadoo's rental property discovery and evaluation platform. These personas represent initial hypotheses based on the product's target market and must be validated through user interviews.

## 2. Primary Persona: Relocating Working Professional

### Persona Profile

| Attribute | Details |
|---|---|
| Persona name | Rahul Sharma |
| Age | 24-30 years |
| Occupation | Software Engineer or Business Analyst |
| Current location | Another Indian city |
| Destination | Bangalore |
| Housing requirement | 1BHK rental apartment |
| Budget | ₹12,000-₹25,000/month (illustrative) |
| Technical proficiency | High |
| Search urgency | High when joining a new job |

*Note: Name, age, budget, and background are illustrative, not research findings.*

### Goals

- Find a suitable rental before relocating.
- Stay within a defined housing budget.
- Minimize commute time to the workplace.
- Avoid unnecessary property visits.
- Make a confident decision using reliable information.

### Pain Points

- Property information is scattered across platforms.
- Listing photographs may not accurately communicate the layout.
- Deposits and maintenance charges complicate budgeting.
- It is difficult to evaluate an unfamiliar locality remotely.
- Coordinating property visits consumes time.

### Behaviors

- Searches online before contacting owners or agents.
- Uses maps to evaluate workplace proximity.
- Saves listings and compares them manually.
- Communicates with property owners through calls or messaging.
- Prefers digital tools that reduce repetitive work.

### Jadoo Value Proposition

Jadoo helps Rahul filter relevant properties, understand upfront and recurring costs, evaluate commute convenience, compare alternatives, and inspect supported properties remotely.

### Success Scenario

Rahul enters his budget, workplace location, and furnishing preferences. He compares shortlisted properties using standardized information and identifies suitable options before travelling to Bangalore.

## 3. Secondary Persona: Student or Fresh Graduate

### Persona Profile

| Attribute | Details |
|---|---|
| Persona name | Priya Verma |
| Age | 21-25 years |
| Occupation | Student, intern, or recent graduate |
| Current location | Outside Bangalore |
| Housing requirement | Affordable 1BHK or independent accommodation |
| Budget | ₹8,000-₹18,000/month (illustrative) |
| Technical proficiency | High |
| Search urgency | Medium to high |

*Budget ranges are illustrative assumptions and should be validated against current listings and user interviews.*

### Goals

- Find accommodation within a limited budget.
- Understand the deposit and recurring expenses.
- Stay near college, work, or public transport.
- Identify furnished properties and essential amenities.

- Difficulty distinguishing affordable properties from properties with hidden costs.
- Dependence on family members, agents, or acquaintances for advice.

- Compares rent, furnishing, and amenities.
- Consults friends, family, or seniors.
- Prefers clear photographs, accurate descriptions, and transparent pricing.

### Jadoo Value Proposition

Jadoo provides a structured way to filter affordable properties, compare total costs, and shortlist suitable homes based on location and essential amenities.

### Success Scenario

Priya sets her budget and preferred locality, filters properties by furnishing and amenities, compares the final costs, and saves suitable options to discuss with her family.

## 6. Shared User Needs

Across all three personas, Jadoo should investigate the following needs:

1. **Relevant discovery:** Find properties matching budget, location, and essential requirements.
2. **Cost transparency:** Understand rent, deposits, maintenance, and other known expenses.
3. **Comparable information:** Evaluate multiple properties using consistent attributes.
4. **Location context:** Understand commute options and nearby facilities.
5. **Remote evaluation:** Inspect available property photos, floor plans, or virtual tours.
6. **Shortlisting:** Save and revisit properties without repeating the search.

## 7. Jobs to Be Done (JTBD)

### Primary Job

"When I need to find a rental home in Bangalore, I want to evaluate suitable properties using my budget, location, commute, and living requirements so that I can shortlist the right options without spending excessive time on manual comparisons."

### Supporting Jobs

- When reviewing a listing, I want to understand the full cost so that I can avoid exceeding my budget.
- When comparing two properties, I want consistent information so that I can make a rational choice.
- When evaluating an unfamiliar locality, I want relevant location information so that I can assess convenience.
- When searching remotely, I want a better understanding of the property's layout so that I can decide whether a physical visit is worthwhile.

## 8. MVP Design Implications

The personas suggest the following initial product priorities:

- Budget and locality filters.
- Rent, deposit, and maintenance details.
- Standardized property detail pages.
- Side-by-side comparison.
- Saved properties and shortlists.
- Commute destination and travel information.
- Virtual inspection for properties with supported media.

Advanced personalization and AI recommendations should remain secondary until the core workflow is validated.

## 9. Validation Plan

Conduct interviews with 10-15 recent Bangalore rental seekers across the three segments.

For each interview, document:

- Previous rental-search experience.
- Most important selection criteria.
- Number of properties evaluated and visited.
- Tools and workarounds currently used.
- Main reasons for rejecting a property.
- Information missing during decision-making.
- Features that would materially improve the process.

Update these personas based on recurring evidence rather than individual opinions alone.

## 10. Conclusion

Jadoo's primary persona is the relocating working professional who needs to evaluate Bangalore rental properties remotely. Students and fresh graduates represent a budget-sensitive secondary segment, while existing renters provide an additional use case for property comparison.

These personas establish the foundation for the next document: mapping how users discover, evaluate, shortlist, and select rental properties through Jadoo.
